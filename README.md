<b>About this tool</b>
<p>A drafting aid for the General Medicine admission note. Fill the blanks, add the order sets that apply, then copy the whole note into the electronic record.</p>
<p>Everything runs inside this browser. Nothing is saved; nothing is sent anywhere, and the tool works with no internet connection. Light and dark follow whatever this computer is set to. Closing the tab discards the note, so copy it out before you leave — the browser will warn you if you try to leave with work that has not been copied.</p>
